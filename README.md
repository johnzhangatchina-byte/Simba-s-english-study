# 小队电台英语

这是一套可以自己运行的静态网页英语课，给 9 岁左右、英语较弱、喜欢小队和地图的孩子使用。每天 10 到 15 分钟，含周六和周日，一共 52 周、364 课。每天学习五句话，每句话都有对应的插图；完成当天任务后，会解锁一条带中英文发音和配图的游戏小贴士。

本产品是英语听说练习，只用小队、地图、方向和沟通用语。中国区 App Store 上《三角洲行动》当前年龄分级为 18+。本课不打开该游戏，也不增加游戏时间。

没有账号，没有后台服务器，不依赖 DuoLingo、少儿趣配音或其他课程平台。进度保存在这台设备的浏览器里。

## 怎么打开（请按这个做）

请不要把 `index.html` 当普通文档双击打开后来录音。很多浏览器把这种 `file://` 地址视为不安全环境，会禁止麦克风，服务工作线程（离线缓存）也可能无法注册。听示范有时还能用，但「按住说话」往往不行。

推荐做法：

1. 把整个 `simba-english-web` 文件夹放到电脑上（不要只拷其中一个文件）。
2. 在电脑上启动本地网页服务，再用浏览器打开 `http://localhost:8080`。
   - Windows：双击 `start-windows.bat`。
   - macOS 或 Linux：在终端进入本文件夹，执行 `./start.sh`（需要已安装 Python 3）。
3. 看到终端或窗口提示后，用 Chrome、Edge 或 Safari 打开 http://localhost:8080
4. 第一次使用时允许麦克风。孩子即可开始「今天的任务」。

这样在同一台电脑的浏览器里，录音、对照回放和离线缓存都可以用。

## 放到手机或平板上用

手机和平板要使用麦克风，通常必须通过 **HTTPS** 打开（`http://192.168.x.x` 这种局域网地址往往也不被允许录音）。

可以把整个文件夹拖到静态网站托管，得到一个 https 地址，再在手机或平板浏览器里打开，或「添加到主屏幕」。

一种无需使用 Git 的做法：打开 https://app.netlify.com/drop ，把本文件夹拖进去，获得 `https://…….netlify.app` 地址。未登录时可能先有临时访问限制，按页面提示领取或注册后即可给家里使用。该服务在国内网络下有时不稳定；若打不开，可改用阿里云 OSS、腾讯云 COS 等国内对象存储的「静态网站托管」，并开启 HTTPS。这些只是放文件，不需要再买一套课程后台。

更新内容时，覆盖同样的文件后再上传一次即可。

## 孩子怎么用

1. 打开首页，点「开始今天的任务」。
2. 先看图、听示范（可点慢速，可点「中文」看意思）。每天有五句话。
3. 按住橙色按钮说话，松开后可点「听示范」和「听我的」做对比。系统会给出简单的三档提示（再试一次 / 很接近 / 太棒了），不会因为分数低而卡关。
4. 做当天的小任务：平日是听音选意思，周六是在简易地图上点地点，周日是复习汇报。
5. 完成后得到一枚贴纸，并解锁今日「游戏小贴士」（配图 + 中英文对照 + 发音）。首页可以打开「游戏小贴士」菜单，查看已经解锁的贴士；还没完成的课，贴士不会提前出现。进度会记在这台设备上。

「今天的任务」会自动从还没完成的第一课开始。漏了某天也不会把很多课堆在一起。

## 家长角

首页右上角进入。第一次请设定 4 位数字密码。里面可以看完成了多少课，并打开任何一周进行练习。也可以清除本机进度。

## 音频说明

- 第一周（第 1 周，周一到周日）已经预置了电脑生成的英语示范音频（espeak-ng，发音偏机械，但可以离线播放）。
- 其余各周若还没有 mp3，会自动改用浏览器自带的英语朗读（Web Speech Synthesis）。不同手机、电脑的声音质量不一样，有的系统需要先在设置里下载英语语音包。
- 你可以日后自己录制更自然的示范音，按 `audio/README.txt` 里的文件名放进 `audio/` 文件夹，就会优先播放你的 mp3。

## 如何更新课程或音频（不用后台）

1. 编辑或替换 `data/curriculum.json`（全年课表）。
2. 如有新的示范音，放到 `audio/`，文件名与课表里的 `audio` 字段一致。
3. 打开根目录的 `sw.js`，把开头的 `VERSION` 改成一个新值，并与 `data/curriculum.json` 里的 `cacheVersion` 保持一致（当前为 `simba-squad-v2`）。
4. 保存后重新用本地服务或重新上传文件夹，在浏览器里打开一次（需要短暂联网或本地刷新），新版本会被缓存下来。之后仍可离线使用。

## 文件说明

- `index.html`：页面入口
- `css/app.css`：样式
- `js/app.js`：全部课程逻辑（听、录、对比、地图任务、贴纸、游戏小贴士、家长角）
- `data/curriculum.json`：52 周 × 7 天的课程数据（每天 5 句话 + 一条 tip）
- `images/`：可复用的课程插图（短语、贴士和地图地点共用同一套图画）
- `audio/`：示范音频（已包含第一周原来的 3 句；新增句子使用系统朗读）
- `sw.js`：离线缓存；更新内容时请改 `VERSION`（需同时缓存新图片和新课表）
- `start.sh` / `start-windows.bat`：本地启动
- `tools/serve.ps1`：Windows 本地小服务
- `tools/build_curriculum.py`：如需重新生成课表可运行它
- `tools/course_extras.py`：每天多出的两句话，以及全年游戏小贴士
- `tools/build_images.py`：如需重新生成插图可运行它
- `README.md`：本说明
- `manifest.webmanifest`：添加到主屏幕时使用

## 现实预期

按每天 10 到 15 分钟、含周末坚持一年计，课时大约 60 到 90 小时，再加上学校英语。从较弱的三年级或不稳的 A1 出发，可以明显进步：更敢说，能听懂慢速、熟悉的指令，能用短句谈地图、装备和简单设计。不会变得流利，也到不了稳固的 A2。

本文件夹就是可运行的产品，可用于家庭自用，也可由你自行托管后运营。商店上架或备案等事项如需另行办理，与本网页能否在浏览器里使用不是一回事。
