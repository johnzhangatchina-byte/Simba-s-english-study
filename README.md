# 小队电台英语

给孩子的英语听说课。这是一套静态网页，没有账号，也没有后台服务器。每天大约 10 到 15 分钟，含周六和周日，一共 52 周。进度保存在这台设备的浏览器里。

课程只用小队、地图、方向和沟通用语。

## 在线课程

请用这个地址打开（保留末尾的斜杠）：

https://johnzhangatchina-byte.github.io/Simba-s-english-study/

电脑、手机和平板都可以用。不要把 `index.html` 当普通文件双击打开。`file://` 地址通常不能录音，也不能使用离线缓存。

## 在手机或平板上打开

录音需要 HTTPS。请用 Safari、Chrome 或 Edge 打开上面的地址，不要用微信或其他 App 里的内置浏览器。

1. 在手机或平板浏览器中打开上面的链接。
2. 第一次使用时允许麦克风。
3. 在浏览器菜单里选择「添加到主屏幕」（Safari）或「安装应用 / 添加到主屏幕」（Chrome、Edge）。之后可以从桌面图标打开。
4. 第一次需要联网。页面会把课程和第一周示范音缓存到这台设备。之后没有网也可以继续使用已经打开过的内容。

## 孩子怎么用

1. 打开首页，点「开始今天的任务」。
2. 先听示范。可以点慢速，也可以点「中文」看意思。
3. 按住橙色按钮说话，松开后点「听示范」和「听我的」做对比。
4. 做当天的小任务。完成后得到一枚贴纸。进度记在这台设备上。

「今天的任务」从还没完成的第一课开始。漏了一天也不会把很多课堆在一起。

## 家长角

首页右上角进入。第一次请设定 4 位数字密码。里面可以看完成了多少课，打开任意一周练习，也可以清除本机进度。

## 音频

第一周（周一到周日）已经带有示范 mp3，可以离线播放。其余各周如果还没有 mp3，会改用浏览器自带的英语朗读。有的手机需要先在系统设置里下载英语语音。

以后可以按 `audio/README.txt` 里的文件名，把更自然的示范音放进 `audio/`。更新课程或音频后，把根目录 `sw.js` 里的 `VERSION` 改成一个新值（例如 `simba-squad-v2`），再打开一次网页，离线缓存才会换成新内容。
